## What's new

- **Breaking CLI change:** `openjev serve` replaces `openjev --serve`. There is no
  compatibility alias. Put server options (`--host`, `--port`,
  `--request-timeout-secs`, `--api-key-env`) after `serve`. The HTTP API is unchanged.
- **`openjev demo`** runs eight HTTP examples against an already-running server,
  without loading another model. Covers Choice, Noul, Score, and mixed questions.
- Demo output includes the exact request, response, timing, and execution
  metadata. Use `--pretty` for a JSON array; otherwise results stream as JSONL.
  Custom server URLs, bearer-secret environment variables, and request timeouts
  are supported.
- Public curl installer with checksum verification and macOS quarantine handling.
- Reworked README and a short, explicitly illustrative server/curl walkthrough,
  with copyable requests at [docs/demo.md](https://github.com/codesoda/openjev-rs/blob/v0.2.0/docs/demo.md).

## Install or upgrade

```sh
curl -fsSL https://raw.githubusercontent.com/codesoda/openjev-rs/v0.2.0/install.sh | sh -s -- --version v0.2.0
```

Then, in separate terminals:

```sh
# Download once, or reuse your existing cache
openjev models pull qwen3-0.6b
openjev serve --offline --model qwen3-0.6b
```

```sh
openjev demo --pretty
```

Restart an existing server to use the new binary. Model weights are not bundled.

## Unchanged limitations

This release changes the CLI and documentation, not model quality. Shared
execution still explicitly falls back to serial where numerical verification
fails. Probabilities remain conditional and uncalibrated; typed output can be
wrong. The macOS binary is not signed/notarized. Calibration and the remaining
M6/M7 work are not completed by this release.
